# In On It

[![Watch the In On It demo](https://img.youtube.com/vi/nvCzdfgDqBM/maxresdefault.jpg)](https://www.youtube.com/watch?v=nvCzdfgDqBM)

▶ **[Watch the demo on YouTube](https://www.youtube.com/watch?v=nvCzdfgDqBM)**

Many children of immigrants understand their family's language but miss the cultural context behind it: the pun, the idiom, the old reference that makes everyone else laugh. In On It is a wearable listener and companion app that closes that gap.

The listener hooks around your outer ear. When you miss something, double-tap it and hear a short whisper explaining the context. The explanation uses simple words in your family's language, matched to your level, with English only when you ask. **Watch** mode is for shows and YouTube. **Talk** mode is for live conversations with grandparents, aunties and uncles, where it waits for a pause and can suggest a simple reply.

Setup starts by asking which language your family speaks, then runs a short level check where "I don't know" is a welcome answer. Moments you ask about are saved so you can revisit them. Optional recording, used only with everyone's consent, lets you replay a conversation later.

AI explains the joke. Your family explains why it matters. In On It helps you join the conversation instead of watching it.

Built for the BSAIC Hackathon.

## Run locally

```bash
npm install
npm run dev
```
